# Delightful Delivery Hub

You are building a 3-sided food delivery marketplace like Zomato/Swiggy.

Create ONE web application with role-based access.

User roles:
1. CUSTOMER
2. RESTAURANT
3. DELIVERY_PARTNER
4. ADMIN

Rules:
- Each role must have a separate dashboard
- Separate navigation per role
- Role-based routing and route guards
- One centralized backend
- Clean scalable architecture

Use Supabase for:
- Authentication
- Database
- Real-time subscriptions

Confirm when foundation is ready before proceeding.
